software

Open-source tools for precision cosmology, from Euclid pixels to posteriors.

Euclid will map a third of the sky and billions of galaxies. Turning that map into answers about dark matter, dark energy and gravity takes more than data: it takes fast, tested and open software. I build that software in the open, with the community, so that every number in a Euclid cosmology paper can be checked, reproduced and improved by anyone.

## The CLOE ecosystem

The next generation of the Cosmology Likelihood for Observables in Euclid: a modular, pip-installable stack that takes you from cosmological parameters to Euclid likelihoods for every primary probe.

cloelib creator & lead developer

The theory engine behind Euclid cosmology.

Euclid-like observables (angular power spectra, correlation functions, COSEBIs, spectroscopic multipoles) in minutes. It plugs into Boltzmann solvers and emulators (CAMB, CLASS, EuclidEmulator2, BACCO, CosmoPower-JAX, COMET and more) through clean Python protocols, and ships with a JAX playground for gradient-based inference.

pip install cloelib

code PyPI paper

cloelike creator & lead developer

Where theory meets Euclid data.

Likelihoods for all Euclid primary probes: 3×2pt in harmonic and real space, BNT C(ℓ), COSEBIs, spectroscopic full-shape and BAO, and their joint analysis. One pip install brings in the whole stack.

pip install cloelike

CLOE core developer

The original Euclid likelihood.

The Euclid Consortium code that set the standard for combined photometric and spectroscopic analyses and powered the official Euclid forecasts and validation campaigns. It is the foundation the new ecosystem is built on.

## Euclid data & statistics
euclidlib core developer

Euclid data, ready for science in one line.

A community Python library for reading Euclid's cosmology-ready data products (redshift distributions, two-point statistics, covariances and more) without wrestling with file formats.

pip install euclidlib

code PyPI

darkflipper creator

Flip the dark side of statistics in cosmology.

Figures of Merit, Figures of Bias, p-values and tension metrics, with consistent definitions, so systematics studies are robust, transparent and publication-ready.

pip install darkflipper

## Open science & teaching

Learn Bayesian cosmology by doing it.

Hands-on notebooks covering everything from measuring H₀ with supernovae to running full cosmology chains and model comparison with Cobaya.
